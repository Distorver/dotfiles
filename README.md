## 💻 Tech Stack & Customization

This setup is built on **Arch Linux** and optimized for a **ThinkPad** workflow.

| Layer | Component |
| :--- | :--- |
| **Compositor** | Hyprland |
| **Status Bar** | Waybar |
| **Notifications** | SwayNC |
| **Launcher** | Rofi |
| **Colors** | Generated via Pywal |
| **Terminal** | Kitty |
